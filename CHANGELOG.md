# Changelog

## 2026-11-05: first release in this repository

All tools gathered into one repository and given version numbers.

- **Effect Keys 1.0.0**: panel and Hammerspoon helper now kept together. Helper gained a version line.
- **Split Stacker 1.0.0**: added unchanged.
- **beatmarkers 1.0.0**: first numbered version. Added `--version` flag. Includes the double-click installer and Make Markers launcher.
- **Cut In/Out 1.0.0**: first numbered version.
- **Logo Layout Panel 4.0.0**: renamed from `LogoLayoutPanel_v4.jsx` to `LogoLayoutPanel.jsx`; the version now lives inside the file.
- **Trim Logos 1.0.0**: first numbered version. Moved next to the Logo Layout Panel, which its read-me covers.
- **Install Hammerspoon Shortcuts 1.0.0**: new installer for the Hammerspoon helpers. Backs up existing scripts and asks before installing Cut In/Out.
