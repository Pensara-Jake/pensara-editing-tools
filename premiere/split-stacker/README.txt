Split Stacker - Premiere Pro UXP panel

Load it (one-time):
1. Premiere Pro > Settings > Plugins > tick "Enable developer mode", restart Premiere.
2. Install "UXP Developer Tools" from the Creative Cloud app and open it.
3. Click "Add Plugin", choose this folder's manifest.json, then click "Load".
4. In Premiere: Window > UXP Plugins > Split Stacker.

Use it:
1. Duplicate your 16x9 edit, set the copy to 1080x1920 (Sequence > Sequence Settings).
2. In the vertical sequence, select both halves of the split screen(s).
3. Click "Restack selected". Undo with Ctrl/Cmd+Z if needed.
